# Klickbarer OrdiSchool-Prototyp

Dieser Frontend-Prototyp gehört zu v0.0.5. Er ist eine Navigations- und Interaktionsdemo für Planbearbeitung, Konfliktprüfung, Vertretungen, persönlichen Stundenplan, Klassenbuchhinweise, Aufgaben, Räume, Mitteilungen und Termine.

## Öffnen

`index.html` lokal in einem aktuellen Browser öffnen. Die Datei benötigt weder Server noch Installation und lädt keine externen Bibliotheken, Schriften oder Daten.

## Demo-Abläufe

### Planänderung mit menschlicher Freigabe

1. In der Navigation **Planung** öffnen.
2. Einen Stundenblock anklicken oder den angezeigten Konflikt lesen.
3. **In Entwurf übernehmen** anklicken.
4. **Zur Freigabe vorlegen** wählen.
5. **Freigabe im Prototyp simulieren** wählen.
6. Unter **Mein Stundenplan** ansehen, dass die Änderung erst danach in der persönlichen Ansicht auftaucht.

### Vertretung

Unter **Vertretungen** einen Vorschlag vormerken. Er erhält zunächst den Status „Vorgemerkt“ und wird nicht veröffentlicht.

### Klassenbuchhinweis

Unter **Klassenbuch** einen Hinweis prüfen oder als geprüft markieren. Der Prototyp kennzeichnet ausdrücklich, dass er den Eintrag nicht automatisch verändert.

### Weitere Ansichten

Dashboard-Karten und Hinweisaktionen verlinken in die passenden Arbeitsbereiche. Aufgaben, Räume und Termine enthalten beispielhafte Formular- und Sichtbarkeitszustände.
